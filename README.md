#  Tic-Tac-Toe AI

A Python Tic-Tac-Toe game where you play against an unbeatable AI. The AI uses the Minimax algorithm with Alpha-Beta Pruning.

## Installation guide

### 1. Install Python
Check if you have Python by opening your terminal and typing: `python --version`. 
If you don't have it, download it from python.org. (Windows users: Make sure to check "Add Python to PATH" during installation).

### 2. Get the Code
Click the green "Code" button at the top of this repository and select "Download ZIP", then extract it. 
Alternatively, clone it via terminal: 
```bash
  git clone https://github.com/actualakib/tictactoe.git 
```
### 3. Install Pygame
Open your terminal, navigate to the extracted game folder, and run:
`pip install pygame`

### 4. Play!
While still in the terminal inside that folder, run:
`python runner.py`


##  Files Included
* runner.py: The visual game interface.
* tictactoe.py: The AI logic and game rules.
* requirements.txt: Project dependencies.
* OpenSans-Regular.ttf: Font used in the game.
